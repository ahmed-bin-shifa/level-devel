# TROLL RUN — Rage Protocol

A standalone browser platformer. No build step, packages, backend, or API key required.

## Run locally
Open `index.html` in a modern browser. For the most reliable audio behavior, use a local static server or GitHub Pages.

## Controls
- **A / D** or **← / →**: move
- **Space / W / ↑**: jump
- **R**: restart the current stage
- **Shift**: sprint
- Touch controls appear on smaller screens.

## Audio
Browsers block autoplay audio until a user gesture. Press **START THE SUFFERING** or **ENABLE THE CHAOS** once to enable the repeating spoken chant and original synthesized beat. Use **MUTE AUDIO** to stop it.

## GitHub Pages
In the repository settings, open **Pages** and select the `main` branch with the `/(root)` folder as the publishing source. Once Pages is enabled and deployed, the game is at:

`https://ahmed-bin-shifa.github.io/level-devel/troll-run/`

If Pages is not enabled for this repository, that URL will not work until a Pages deployment is configured.
